# 自动点击助手（Auto Click Assistant）

一个 Chrome MV3 扩展：录制你的鼠标键盘操作，支持回放、循环回放，代替你执行重复的劳动。

## 功能

- **录制**：点击侧边栏「创建」，在页面上正常操作（点击、输入、按键、滚动、提交表单），自动记录。
- **回放**：一键回放录制好的操作，有可视化鼠标指针和高亮反馈。
- **循环回放**：设置「次数」和「间隔」，自动重复执行多轮；遇到步骤失败自动跳过本轮进入下一轮。
- **刷新/跳转兼容**：录制中含刷新页面的操作，回放时会真实刷新并自动续跑。
- **元素智能定位**：按 `id → 结构 XPath → class 序号 → 文本` 多级兜底定位元素，应对动态页面。
- **导入/导出**：录制可导出为 JSON 文件分享给他人，他人一键导入即可使用。
- **执行报告**：单次回放结束弹出执行统计（成功率、耗时、未找到元素数），可导出 HTML 报告。

## 安装

1. `git clone` 或下载本仓库源码。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录。
4. 点击工具栏上的扩展图标，打开侧边栏开始使用。

## 使用

1. 侧边栏点「创建」开始录制 → 在页面上操作 → 点「结束录制」。
2. 在任务列表中设置「次数」「间隔(秒)」，点「播放」。
3. 页面上出现回放控制面板，点「开始」执行；支持暂停、单步调试、结束。

## 说明

- 所有录制数据只存储在浏览器本地（`chrome.storage.local`），不上传、不外发。
